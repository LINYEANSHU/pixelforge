# PixelForge —— 导出格式规范

版本 1 · 时间基 1/60

所有导出由同一确定性管线生成：`效果配置 + 种子 + 帧号 k` → `渲染帧`。**不录屏、不依赖实时帧率。**

---

## 1. 时间规则（最重要）

- `fps = 60`，时间基 `"1/60"`。
- 第 k 帧的采样时间：`t(k) = k / 60` 秒（精确有理数）。
- JSON 中提供 `frameDurationMsExact: 16.666666666666668` 仅供展示。**消费方必须以 `k / fps` 计算时间，禁止以累加 16 或 16.667ms 的方式重建时间轴**（会产生累计漂移）。
- 帧数：`N = round(durationSec × 60)`。
- 循环效果：导出 k ∈ [0, N-1]，**帧 N ≡ 帧 0（逐位一致），因此不导出第 N 帧**；播放到末尾后接第 0 帧即为无缝循环。
- 非循环效果：导出 k ∈ [0, N-1]。

## 2. 单帧 PNG

- RGBA（colorType 6）8bit，直通 alpha（非预置乘）。
- 背景全透明：不含预览棋盘格、测试场假人或黑色背景。
- 引擎建议：加法类粒子以 Additive/Screen 混合叠回游戏；普通混合部分（烟/碎片）直接使用其 alpha。

## 3. PNG 序列 + timeline.json（ZIP）

ZIP 内含：

```
<name>_0000.png ... <name>_<N-1>.png
<name>.timeline.json
```

`timeline.json` 结构：

```json
{
  "format": "pixelforge.timeline",
  "version": 1,
  "app": "PixelForge 特效工厂 1.0.0",
  "name": "magic_explosion",
  "fps": 60,
  "timebase": "1/60",
  "frameCount": 132,
  "durationSec": 2.2,
  "loop": false,
  "frameDurationMsExact": 16.666666666666668,
  "frameTimeRule": "frameTimeSec(k) = k / fps。请勿以累加舍入毫秒的方式重建时间轴。",
  "canvas": { "width": 256, "height": 256 },
  "recipe": { "...": "完整配方，可被应用加载" },
  "frames": [ { "index": 0, "file": "magic_explosion_0000.png", "timeSec": 0 }, ... ]
}
```

## 4. Sprite Sheet（ZIP）

ZIP 内含若干页 PNG 与一个 `<name>.sheet.json`。页宽高 ≤ 上限（默认 4096，可选 1024/2048/4096）；单元格 = 画布边长，帧间距 = padding（默认 2px）。**逐页渲染→编码→释放**，永不驻留全部原始帧，也绝不拼接超大 Canvas。

`sheet.json`（Aseprite 纹理图集兼容 + pixelfx 扩展元数据）：

```json
{
  "frames": {
    "magic_explosion_0000": {
      "index": 0,
      "frame": { "x": 0, "y": 0, "w": 256, "h": 256 },
      "rotated": false, "trimmed": false,
      "spriteSourceSize": { "x": 0, "y": 0, "w": 256, "h": 256 },
      "sourceSize": { "w": 256, "h": 256 },
      "duration": 16.666666666666668,
      "page": 0,
      "timeSec": 0,
      "anchor": { "x": 128, "y": 128 }
    }
  },
  "meta": {
    "app": "PixelForge 特效工厂 1.0.0",
    "format": "RGBA8888", "scale": "1",
    "pixelfx": {
      "fps": 60, "timebase": "1/60",
      "frameDurationMsExact": 16.666666666666668,
      "frameTimeRule": "frameTimeSec(k) = k / fps",
      "loop": false, "frameCount": 132,
      "padding": 2,
      "cell": { "w": 256, "h": 256 },
      "anchorSpec": "每帧锚点为所在单元格中心，单位为页内像素",
      "pages": [ { "image": "magic_explosion_sheet_00.png", "page": 0, "size": { "w": 4096, "h": 4096 }, "frames": [0, 1, ...] } ],
      "recipe": { "...": "完整配方" }
    }
  }
}
```

- `frames` 键名 = `<名称>_<4位帧号>`；顺序 = `index` 升序。
- Phaser（hash atlas）、Godot/Unity 的 Aseprite 导入器可直接读取 `frames`/`meta`。

## 5. 配方 JSON（.pfx.json）

```json
{
  "format": "pixelforge.recipe",
  "version": 1,
  "app": "PixelForge 特效工厂 1.0.0",
  "template": "magic_explosion",
  "params": { "scale": 1, "intensity": 1, "durationSec": 2.2, "color": "magicBlue", "smoke": 1 },
  "seed": 42,
  "loop": false,
  "budget": 1000,
  "canvasSize": 256,
  "note": ""
}
```

组合效果使用 `combo: true` + `items: [{config, start, dur, off, scale}]`。

加载规则（应用内与消费方一致）：
- `format`/`version` 不符 → 拒绝；模板不存在 → 拒绝；参数类型错误/未知参数 → 拒绝并列出原因；
- 数值越界 → 钳制到 schema 范围（不拒绝）；
- `seed` 必须为数字；`params` 必须为对象。

## 6. 采样与一致性

- 预览（连续时间 t）、拖动时间轴、逐帧、导出全部调用同一求值函数，第 k 帧逐位一致（测试：解码导出 PNG 与直接渲染逐字节相等）。
- 导出可以慢于实时（实测约 500 帧/秒 @256px），产物时间轴恒为 60FPS。
