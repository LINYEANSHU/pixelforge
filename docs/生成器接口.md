# PixelForge —— 生成器接口说明

## 1. 概念模型

```
配方(配置+种子) ──► 模板build() ──► 图层规格数组 ──► Layers.make(spec, seed, 层号, 循环周期)
                                                        │
渲染帧(k) = t = k/60 ──► 每层 render(t, Raster) ──► 双缓冲(颜色+加法光) ──► composite() ──► RGBA
```

一切状态都是 `(种子, 层号, 槽号)` 与时间 t 的纯函数——没有"模拟历史"。这带来逐位复现、O(1) seek、循环无缝与零逐帧分配。

## 2. 模板定义

```js
PF.TEMPLATES['my_effect'] = {
  id: 'my_effect',
  name: '我的效果',            // 中文名（UI/解析器使用）
  category: 'explosion',       // PF.CATEGORIES 之一
  loop: false,                 // 循环模板（引擎自动锁相）
  duration: 2.2,               // 默认时长（秒）；loop 模板即周期
  desc: '一句话描述',
  params: [                    // 参数 schema（数组）
    { key: 'scale',      label: '整体尺寸', type: 'range', min: 0.5, max: 2, default: 1, step: 0.01 },
    { key: 'color',      label: '色板',     type: 'ramp',  default: 'fire', options: [...命名色板] },
    { key: 'angle',      label: '方向',     type: 'angle', default: 0 },   // 度
    { key: 'loopFlag',   label: '开关',     type: 'bool',  default: false },
  ],
  build(p, pal) {              // p=参数, pal=palette 模块
    return {
      layers: [ /* 图层规格，见 §3 */ ],
      shake: { t0: 0.36, amp: 0.02, freq: 9, dur: 0.5 },   // 可选震屏
      meta:  { thumbTime: 0.42 },                          // 可选缩略图时刻
    };
  },
};
```

参数校验自动进行：未知参数/类型错误 → 拒绝；越界数值 → 钳制。

## 3. 图层词汇（8 种）

所有图层公共字段：`type, t0, t1`（秒，非循环）+ `ramp`（色板）+ `glow`（光缓冲强度）+ `mode`（0普通混合 1加法 2仅光 3普通不加光）+ `alpha`。

| type | 用途 | 关键字段 |
|---|---|---|
| `burst` | 一次性碎片/火花爆发 | `count, angle, spread, spd[a,b], drag, grav, life[a,b], size0[], size1[], kind(0圆斑/1速度拉伸/2自旋长条), spin, jitter, jitterT, flicker, spdPow, fadePow, driftA` |
| `vstream` | 持续发射场（循环安全） | `rate(个/秒), life, spd, drag, grav, jitter, driftA/F, flicker, warm(暖启动), speedLine(速度线), size0/1` |
| `swirl` | 轨道/漩涡（全解析） | `count, r, w(角速度), dir, wob, wobN, converge(内聚), trailK, life` |
| `ring` | 冲击环（颗粒化） | `r0, r1, ease, halfW, halfW1, attack, squishY(地面压扁), grain` |
| `flash` | 复合闪光（白核/主色/外晕） | `r, alpha, attack` |
| `beam` | 光束/光柱 | `from[], to[], width, width1, grow, core, attack` |
| `arc` | 挥砍弧光 | `r, r1, a0, a1(弧度), width, trail` |
| `bolt` | 闪电折线（按代重生成） | `from, to, segs, jag, branches, regen, life, coreW, glowW, impact` |
| `glowspot` | 呼吸辉光底光 | `r, alpha, pulse(Hz)` |

**循环安全规则**（`loop: true` 时引擎自动处理）：vstream 周期对齐效果周期；swirl 角速度锁相为 2πk/周期；glowspot 脉冲锁相；converge/wJit 归零。模板作者需保证半径摆动 `wobN` 为整数周期。

## 4. 预算

`budget`（默认 1000）按"预估活跃粒子"比例收缩各层的 `count`/`rate`，保证 Σ活跃 ≤ 预算。槽化设计使活跃数在渲染中天然有界（无池增长）。

## 5. Renderer 接口（稳定，供未来 GPU 后端）

```ts
interface Renderer {
  resize(size: number); clear();
  fillBg(color: int);                       // 仅预览，导出前总是 clear
  stamp(x, y, r, color, alpha, glow, mode, falloff?);
  ring(x, y, r, halfW, color, alpha, glow, mode, falloff?);
  beam(x1, y1, x2, y2, halfW, color, alpha, glow, mode, falloff?);
  pixel(x, y, color, alpha, glow, mode);
  composite(out?, reduceFlash?): Uint8ClampedArray;   // 颜色+光 → RGBA
  pushTransform(ox, oy, scale); popTransform();       // 组合器世界变换
}
```
当前实现 `PF.CpuRaster`（软件双缓冲）。坐标为世界空间 [-1,1]²，原点居中，y 向下。

## 6. 效果实例 API

```js
const eff = PF.makeEffect({ template, params, seed, budget, canvasSize, loop });
eff.durationSec; eff.frameCount();          // = round(duration*60)
eff.renderFrame(k, raster);                 // 第 k 帧（导出/逐帧路径）
eff.renderLocal(t, raster);                 // 连续时间 t（预览路径）
eff.shakeOffset(t, out2);                   // 震屏偏移（渲染层应用）
const combo = PF.makeCombo({ items: [...≤4], budget, canvasSize });
PF.recipeToJSON(eff) / PF.recipeFromJSON(json)
PF.variant.mutateStyled(config, locks, 'subtle'|'normal'|'wild')
PF.parser.parse('蓝紫色环形爆炸，持续2秒')
```
